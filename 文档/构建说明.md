# 构建说明

## 标准环境

目标为 Windows x86_64，使用 Rust GNU 工具链。本次候选构建使用 Rust/Cargo 1.99.1；其他版本未作完整验证。

从 [Rust 官方网站](https://www.rust-lang.org/tools/install)安装 rustup，然后安装 GNU 工具链：

```powershell
rustup toolchain install stable-x86_64-pc-windows-gnu
```

在仓库根目录执行：

```powershell
& .\命令\构建.ps1
```

默认执行 `cargo build --release --locked`。首次构建需要联网下载 Cargo.lock 中的依赖；依赖已缓存时可加 `--offline`。脚本通过 rustup 查找指定工具链，配置随 Rust 提供的 LLVM 链接器与导入库辅助工具；无需旧项目目录。

成品位于 `中间文件/cargo/release/LiveEarth.exe`。运行不需要 Rust；分发时附上项目 MIT、EarthLiveSharp 声明、Rust 依赖许可汇总及 MiSans 许可/说明，不能仅分发字体文件。

## 可选的本地工具缓存

已拥有完整便携工具缓存时，可用 `-ToolsRoot` 或 `EARTHLIVE_RUST_TOOLS` 指定其根目录，结构为 `rustup/toolchains/stable-x86_64-pc-windows-gnu/bin` 和 `cargo`。相邻 `base/工具链` 存在时会自动复用；它不是克隆本仓库后的必需目录，也不提交到 Git。

## 针对性检查

```powershell
& .\命令\构建.ps1 -CargoArgs @('fmt','--all','--check')
& .\命令\构建.ps1 -CargoArgs @('test','--lib','--locked','--offline')
& .\命令\构建.ps1 -CargoArgs @('clippy','--all-targets','--locked','--offline','--','-D','warnings')
```

根据修改范围选择检查，不要求每次全部执行。常规测试使用临时目录和回环 HTTP 服务器。涉及真实壁纸的专项测试默认忽略，应明确选择后才运行。

`代码/tests/native_acceptance.py` 是可选原生验收工具，需要 Python，并会操作测试窗口及鼠标键盘。不用于普通构建，也不应在用户工作时自动执行；参数见 `--help`。

## 仓库与发布产物

提交源码、Cargo.lock、构建脚本和许可材料。不要提交 `程序/`、`中间文件/`、个人数据、工具链或内部开发记录。EXE 使用 GitHub Releases 分发，文件名固定为 `LiveEarth.exe`，版本在界面与 Windows 文件属性中显示。

当前版本 V2.046 对应 Cargo 0.4.6；“查看更新”仅打开 GitHub 发布页，不自动下载安装。不要把个人运行目录作为 Release 附件。
