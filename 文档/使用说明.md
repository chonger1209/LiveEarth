# 使用说明

## 首次运行

将 EXE 和随附许可放在可写目录，运行 `LiveEarth.exe`。设置保存在旁边的 `数据/settings.json`，上一份有效设置为 `settings-B.json`。默认照片及日志在 `数据/照片`，可在界面修改。字体已内嵌，不需要另外安装。

## 快速上手

新用户首次打开会看到一页式引导：选分辨率 → 选照片目录 → 开始抓取与更新壁纸 → 按需调整壁纸缩放。辅助说明统一为 12 号次要灰色。

“不再自动显示”默认未勾选。勾选并点击“知道了，开始使用”后保存，后续不再自动弹出；不勾选并确认，下次仍显示。点 X 仅关闭本次，不保存该选择。按钮只关闭引导，不代替用户启动抓取。保存失败会反馈；仍以成功保存的偏好为准。

已有用户升级后不强制弹出，可从“项目说明 → 快速上手”随时打开。在这里取消勾选“不再自动显示”并确认，也可以重新开启启动引导。

## 抓取

选择“最新”“指定时刻”或“历史区间”，选择分辨率和目录，再点击“抓取本次”。输入时间可用北京时间或 UTC，分钟须落在十分钟边界。“抓取本次”负责下载，自动换壁纸由定时任务控制。

点击“开始抓取”开启定时检查；“停止抓取”停止后续调度，已运行的任务可用“取消当前任务”另行取消。已经保存的照片保留。历史任务执行期间定时检查等待，不并发执行两批。

源站 PNG 分片拼为完整原图后，以无损 WebP 保存。已有有效归档会被复用；“重新下载并核对已有帧”仅影响手动任务，同内容不重复保存，源站修订另存文件。

## 数量限制

新配置默认最多保留 **99 张**。在设置中输入 **0** 表示不限量。旧配置中已经明确保存的值继续生效。

最新影像新增保存成功后，超过上限就按观测时间清理最旧的本程序归档。清理是直接删除，不进入回收站；普通文件和日志不参与。PNG、WebP、同一时间不同分辨率分别按文件计数。

指定时刻与历史区间自身不触发清理，但其文件参与以后最新任务的清理。长期收藏的图片请复制到其他目录。修改上限本身不立即删除，下载失败或复用已有照片也不触发清理。

## 壁纸与设置

勾选“自动抓取成功后应用壁纸”，定时任务会更新壁纸。缩放范围 10%–200%，100% 是原图像素尺寸，大于屏幕部分会裁切；归档原图不受缩放影响。

抓取相关设置在定时关闭且当前任务结束后才能改。修改结束后自动保存；数值拖动释放后保存，输入后按回车或离开输入框。托盘、窗口和自启动设置可随时修改。

## 托盘和自启动

“最小化时收起到托盘”“关闭窗口时收起到托盘”分别控制最小化按钮和 X。彻底退出使用托盘菜单的“退出程序”。

“开机自启动”在当前用户登录 Windows 后运行登记路径下的 EXE。另有自启动时最小化选项。移动后在新位置勾选“开机自启动”，会直接把 LiveEarth 启动项更新到当前 EXE 和数据目录，不再拒绝旧路径。取消勾选会移除该项；普通打开程序不会抢占其他副本的登记，最后一次主动设置的位置生效。配置保存失败会尝试恢复修改前的完整记录。同一路径替换新版 EXE 不需要重新登记。

## 日志和数据

运行记录常驻显示，详细记录按北京时间每天写入照片目录的 `运行记录-YYYY-MM-DD.log`。当天重启会追加，删除日志后下一条事件会重建。更换照片目录不会自动搬走旧照片或旧日志。

界面“已保存”是本次启动累计新增数，不是目录当前文件数量；“缺失”是源站返回缺失的观测记录，网络故障不算缺图。清理数量合并在任务结果中，不逐张刷屏。

`数据/wallpaper-A.bmp` 与 `wallpaper-B.bmp` 是固定两份桌面缓存。`.instance.lock` 与 `.archive.lock` 用于防止同时写入，不需要手动处理。换电脑继承设置后应检查照片绝对路径；仅携带 EXE 和许可可从默认配置开始。

## 错误与限制

最多跟随 3 次同源、保持协议的跳转；正式源站使用 HTTPS，不接受跨域、降级到 HTTP 或携带账号信息的跳转。异常跳转会明确记录并退避重试，不直接永久关闭定时任务。

目录通知正常时，清单增量更新；通知不可用时降级为每批任务扫描一次、批内复用，后续任务会尝试恢复通知。切换模式时各记一条日志，读取目录本身失败仍会报错；扫描在文件之间响应取消。

临时网络故障会退避重试；不可恢复的存储或请求错误会记录原因并暂停自动抓取。缺失历史帧会跳过；源站是否保留某个时间点不由程序决定。

锁屏不等于睡眠。睡眠、关机、注销期间无法抓取，恢复后检查最新影像。软件不是气象预警服务。影像公开使用须遵守 [NICT 使用规则](https://himawari8.nict.go.jp/ja/himawari8-about.htm)。

## 查看更新

点击“查看更新”会用默认浏览器打开 [GitHub 最新正式发布页](https://github.com/chonger1209/LiveEarth/releases/latest)。程序不后台联网检查版本、不自动下载或安装，也不会提示“已是最新版”。下载后先退出程序，在原位置替换 EXE 并补齐许可，保留数据目录。

## 界面主题

主界面、设置、项目说明、快速上手及控件自动跟随 Windows 的深色/浅色主题。窗口背景、文字、按钮、边框、选中/悬停/按下/禁用状态和辅助说明使用配套颜色；字号、按钮形状和布局一致，地球图片保持原色。

开始抓取仍以红色表示，运行中的停止按钮为绿色；工作为青蓝、重试为黄色、停止为灰色，按主题调整明暗。辅助说明保持 12 号，深色用浅灰，浅色用深灰。没有额外主题开关。

## 版本与升级

本版显示 **V2.0.48**，Windows 产品版本为 **2.0.48**、文件版本为 **2.0.48.0**。从旧 V2.047 更新时只替换 EXE 并保留数据和许可；现有配置 schema 和归档 schema 不变，不转换或重命名照片。旧版记录中的版本名为历史事实。
